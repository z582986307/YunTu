# 云图品牌迁移设计

## 目标

平台可见名称统一为“云图用例管理平台”；本地项目目录和 GitHub 仓库使用 `YunTu`；项目自身代码标识和测试依赖目录使用 `YunTu`/`yuntu`。

## 边界

保留数据库表、字段、历史用例、执行记录和上传图片；不修改第三方开源项目的来源链接与版权归属。现有页面路径和后端接口保持不变。

## 实施顺序

1. 以当前已验证功能提交作为回退点。
2. 修改页面文案、项目自身标识、测试与文档，并运行前端测试、生产构建及后端测试。
3. 停止生产服务，核对目标目录不存在，再迁移本地目录与项目依赖路径，重新启动生产服务并检查页面。
4. 将用户拥有的 GitHub 仓库 `z582986307/AgileTC` 更名为 `z582986307/YunTu`，更新本地 `origin`，推送并验证。

## 失败恢复

代码改动可由提交回退；本地目录迁移失败时移回原路径。GitHub 更名若受权限或接口限制，保留本地提交及原仓库，不修改远端地址，并向用户报告。

## 验收

浏览器标题、登录页、导航和文档展示中文品牌；源码中项目自身旧标识消失；用例编辑与测试任务行为、测试结果和图片数据保持；生产构建、测试和服务启动通过；远端仓库与本地目录为 `YunTu`。
