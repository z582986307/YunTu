# 标签删除与折叠重叠修复

基线：master `566141b`。用户本轮三项问题：已添加标签不能删除、标签右上角清除按钮样式、展开折叠短暂重叠。

## 验收口径

1. 工具栏自定义标签删除后不残留为本地新增候选；已应用标签删除当前节点对应资源，保留其他节点同名标签。节点标签悬浮删除可点击并进入现有撤销、自动保存链，不改变普通任务只读权限。
2. 复用现有轻量清除视觉，十字居中，悬浮与聚焦可用，不挤占节点/标签空间，不靠常驻粗重红球表示删除。
3. 展开、收起及连续切换时，新可见节点不能先使用旧坐标与其他节点重叠；最终位置、连接线、折叠计数保持一致，不遮挡整画布、不用任意延时掩盖布局完成。

## 执行与证据

- 主代理旧生产隔离服务实际操作：选中节点、添加默认标签、聚焦节点标签、点击 SVG 清除成功，证明并非所有删除入口都失效。继续覆盖自定义候选残留和悬浮删除时序。
- 单一实施代理按根因调查与 RED/GREEN 修复，提交前前端全量、真实核心浏览器测试、自审；主代理独立代码评审。
- 主代理生产构建、更新隔离测试包，实际浏览器验证删除、保存后刷新与折叠过程；通过后再替换本地生产 Jar，业务数据库不变。
