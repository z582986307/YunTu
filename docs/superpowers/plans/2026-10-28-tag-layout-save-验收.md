# 外观、标签保存与滚动条修复验收

## 范围与结论

沿用原后端数据模型、自动保存及拒绝未知写入保护，不增加整树覆盖或自动重发。两种可编辑模式共用界面：用例编辑、任务中的“编辑用例”。普通任务执行保持内容只读。

| 用户问题 | 处理 | 证据 |
| --- | --- | --- |
| 标签保存失败，清空后不能再次添加 | 修复客户端remove缺失语义，Resource清空删除字段；多选数组隔离 | 真实核心严格JSONPatch回归；浏览器新增/清空/再次新增可保存，隔离库验证 |
| 撤销后保存/重做异常 | 源历史版本单调递增，纯版本确认不清重做栈 | 后端拒绝过期写入回归；浏览器撤销后库base3且无标签，重做后base4且恢复标签 |
| 外观排版上下不齐，标签删除挤动布局 | 标题第一行、按钮第二行；字体5操作同排且在字号上方；标签说明同标题；删除绝对定位 | ReactDOM回归；实际1024宽度无横向溢出，5个字体按钮同一Y |
| 节点标签方角、不能悬浮删除 | 圆角在实际尺寸设定后应用；按悬浮节点清单标签；延迟创建删除控件 | 实际核心浏览器夹具与权限回归；可在节点右上角删除并保存 |
| 搜索首次结果未居中、回车误编辑 | 隔离搜索键盘事件并阻止Enter默认输入；按当前画布中心校准；旧普通布局标记不能永久阻止首次定位 | 真正键盘事件回归；正常/展开外观时简单命中中心误差小于1像素；109节点父模块实际(dx=-1.2px,dy=0.6px) |
| 他人锁定源用例，任务编辑入口提示不明确 | 源锁事件初始化与变更通知；自身任务锁不误禁用；结束编辑保持可用 | 实际双页面禁用提示“源用例被锁定，不可编辑”；源解锁后不刷新恢复入口，进入/结束编辑成功 |
| 滚动条四端空白、折叠后范围不变 | 固定可见内容边界，忽略折叠后代，包含新增节点，读取实时画布尺寸，指针握点同一坐标系 | 真实浏览器四端均显示边界节点，约28px安全余量；99子节点折叠后纵向条消失；矩阵/过期视口回归 |
| 折叠数量按钮过大 | 折叠半径10改8，展开半径6不变 | 实际默认比例按钮约19.2px，99完整显示；超过99保留省略规则 |
| 链接提示文本和计数重叠 | 链接、图片提示输入共享独立76px计数预留区，保持200字与剩余N/200 | 真实Sass+ReactDOM；浏览器用例175字显示25/200、任务编辑200字显示0/200，均不重叠 |
| 链接删除按钮太近 | 右上偏移由(20,-4)改(23,-7)，保留透明悬浮桥 | 实际从链接移向删除按钮可点击并保存；核心事件/桥边界回归 |
| 撤销旁额外插入图片按钮 | 移除重复入口，保留外观图片菜单与粘贴功能 | 两种模式实际检查；React树断言原图片能力仍存在 |
| 外观区与画布层级不清 | 展开外观底部增加1px浅灰分隔线 | 实际样式rgb(226,232,240)，折叠不保留额外内容高度 |
| 标记结果后抖动 | 只移除Progress命令不必要的整图重排；优先级等布局不变 | 真实核心命令测试小/大图均只render；浏览器标记前后文字x/y/width/height完全一致 |

## 已知边界

- 用户确认只有未确认标签，可在刷新部署后重新添加；本轮不宣称恢复已刷新丢失的未确认草稿，也不重放旧未知补丁。
- 远端Undo在接收页无本地历史栈时的既有同步边界未扩展；后端过期写入拒绝保护保留，不宣称全协作历史重写完成。
- 本轮不是5万个节点全量性能重验、HTTPS证书验收或新的Windows ZIP交付；已有ZIP不自动替换。
- 测试在独立数据库3302、HTTP8196进行，不修改业务数据库内容；部署仅替换业务应用Jar并保留旧Jar备份。
